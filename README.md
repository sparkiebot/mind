# Sparkie Mind

Sparkie Mind is the standalone LAN inference service for Sparkie's voice
assistant. It accepts a completed WAV from the robot, passes audio directly to
Gemma 3n, and returns a validated Italian speech response or a constrained tool
proposal.

The project has not been implemented yet. Its design contract is in
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) and [`docs/API.md`](docs/API.md).
